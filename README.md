## 🚀 Featured Project

### GRIDGUARD — AI-Powered Water Leak Detection and Localization System

An interactive water-pipeline monitoring and leak-simulation prototype developed during **TECHX MADRAS 2026 — VerdictX: Code & Conquer**, as part of Team InnovateX.

**Key features:**
- Interactive virtual water-pipeline network.
- Simulated leak scenarios with pressure and flow readings.
- Baseline leak detection using pressure thresholds.
- Dashboard for monitoring network conditions.
- Optional local OPC UA simulator for sample telemetry.
- Dataset preview and GridGuide, a rule-based assistant.

**Important:** GRIDGUARD is an educational simulation. It does not connect to physical water infrastructure, and its leak detection has not been validated for real-world operational use.

🔗 **Project Repository:** [GRIDGUARD on GitHub] https://github.com/Amit-Mavinakatti/GRIDGUARD-AI-Powered-Water-Sustainable-Network-System.git
